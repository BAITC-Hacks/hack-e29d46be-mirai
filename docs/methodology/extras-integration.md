# Подключение дополнительных признаков

```python
from pipeline.extras import compute_extras

per_node, extras = compute_extras(nodes, edges, tx)
if not per_node.empty:
    metrics = metrics.merge(per_node, on="gid", how="left", validate="one_to_one")
```

Входные таблицы соответствуют `docs/CONTRACTS.md §5`; индексы произвольные.
Функция не меняет входы, возвращает строку на каждый gid, включая изолированные узлы.
Нужны только pandas/numpy/networkx из стартовых зависимостей. Ошибка схемы или вычислений →
предупреждение в Python logging, типизированный пустой DataFrame и `{}`.
Пустой результат нельзя трактовать как отсутствие признаков и нельзя делать inner join.
Перед merge исключите уже существующие одноимённые дополнительные столбцы, например
`truncated_by_depth`, чтобы pandas не добавил суффиксы `_x`/`_y`.

В JSON `flags` можно переносить истинные булевы признаки `fast_transit`,
`likely_true_terminal`, `terminal_unknown`, `truncated_by_depth`; `sync_in_days > 0`
означает синхронные входящие. Числовые показатели переносите в `metrics`.
Поля необязательные, общие контракты не меняются. #6 добавляет `in_cycle`,
`repeated_route_count`, а также `extras.cycles`, `extras.repeated_routes`,
`extras.resilience` и метаданные полноты поиска. Gid в per_node — int64;
в глобальном словаре все gid — строки для точности в JavaScript.
Результат глобального словаря проверен через `json.dumps(..., allow_nan=False)`.

Проверка: `python -m unittest discover -s tests -p test_extras.py -v`.
23 теста проверяют окна, отсутствие повторного использования суммы, seed,
границу обхода, синхронность, ошибочные входы, отсутствие мутаций, направление
и ограничения циклов, маршруты, устойчивость, пустой граф, точность больших gid.
Реальный прогон: 2 248 строк без пропусков, примерно 0.24 секунды на машине разработки
(без загрузки parquet). После получения фундамента из main проверено:
`python run.py --no-serve --out /tmp/mirai-extras-validation` — 2.3 секунды,
2 248 узлов, 91 кластер, топ-50, валидация CSV проходит.
Текущий экспортёр ядра сохраняет новые булевы флаги, но его фиксированный список
числовых метрик пока не включает поля extras; требуется подключение владельцем ядра.
