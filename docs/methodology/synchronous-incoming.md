# Синхронные входящие

Для каждой пары (получатель, календарный день) считаем **разных отправителей**,
исключая самопереводы. День считается синхронным при ≥3 отправителях.

- `sync_in_days`: число таких дней у узла.
- `sync_max_payers`: максимальное число разных отправителей за один день.

Повторные переводы от одного отправителя не увеличивают число плательщиков.
Порог 3 отличает несколько независимых плательщиков от единичной связи; это
эвристический порог, не статистическая значимость и не признак преступления.
Суммы не участвуют в счётчике; их надо оценивать отдельно вместе с профилем узла.

Известна дата, но не часы: «синхронность» означает только один календарный день.
Легальные регулярные платежи могут давать тот же сигнал. Отсутствующие входящие
занижают число плательщиков, особенно у seed. На исходных данных: 66 узло-дней у 38 узлов.
