# Гипотеза о конечном получателе

`likely_true_terminal = in_kzt > 0 AND out_deg == 0 AND depth < 4 AND NOT is_seed`.
Сумма и исходящие берутся из наблюдаемых `edges`, а не из полного баланса клиента.
Изолированный узел не получает этот признак.

При обходе по исходящим связям узлы на глубине 4 не раскрывались. Поэтому
`truncated_by_depth = depth >= 4 AND out_deg == 0`; такие узлы никогда не получают
`likely_true_terminal`. `terminal_unknown` отмечает узлы с положительными входящими,
нулевыми исходящими и либо границей обхода, либо статусом seed. Входящие seed неполны.

Это консервативный вариант: он не пытается угадать поведение 4-го колена по похожим
узлам на коленах 1–3. Такое сравнение без размеченных данных не подтверждает сток.
`False` у неизвестного узла означает отсутствие достаточных оснований, не доказанный транзит.

Даже положительный признак — только гипотеза удержания **в наблюдаемом графе за июль**.
Переводы в другой банк, после конца периода или ниже порога 5 000 KZT не видны.
Следующий запрос: полные исходящие за расширенный период, особенно для глубины 4.

Проверка исходного датасета: 1 079 кандидатов; 444 обрезанных узла не помечены terminal;
456 узлов с входящими и без исходящих остаются неопределёнными (444 границы и 12 seed).
