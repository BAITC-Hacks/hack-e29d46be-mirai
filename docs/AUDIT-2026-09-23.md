## Оставшиеся воспроизводимые проблемы

1. POST/api/ask отбрасывает actions, хотя assistant.ask возвращает проверенный путь.
   Поэтому UI не может показать действие. Исправление принадлежит app/ в #31.
2. /api/top доверяет старому CSV: score0.1234 в CSV и0.9452 в графе для одного gid
   дают разные оценки в топе и карточке. Требуется проверка согласованности/fallback (#39).
3. --out поддерживается пайплайном, но текущий сервер использует стандартную outputs/.
   До интеграции явного каталога использовать custom --out только с --no-serve (#31).
4. Граф перегружен подписями и слабоконтрастными связями; пользовательские скриншоты
   переданы в #31. Новый UI ещё не проверен, текущий HTTP smoke не заменяет визуальное ревью.

Локальная ошибка Failed to fetch на порту8018 была связана с остановленным сервером:
после восстановления endpoint клиента ответил200. Это не доказывает отсутствия других
сетевых ошибок, UI обязан показывать понятное восстановление соединения.
