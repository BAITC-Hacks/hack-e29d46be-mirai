2. **Загрузка + метрики** `metrics.py`: in/out степень, суммы, число уникальных плательщиков, pass_ratio, число seed выше по потоку, betweenness/pagerank, профиль относительно своего колена (перцентили).

5. **Приоритет** `priority.py`: формула priority_score (взвешенная сумма понятных компонентов) + top_nodes.csv с `why`.
6. **Экспорт** `export.py`: 3 CSV + graph.json с координатами раскладки. Проверка: 2 248 строк, нет пустых полей, < 5 мин.
7. **[после 17:00] README**: запуск, критерии ролей и пороги (таблица), формула приоритета, ограничения, масштабирование до 1 млн узлов.

### Нурай — интерфейс (`app/`)
1. **[14:40–15:30]** `app/server.py` на FastAPI: все эндпоинты из CONTRACTS.md §3, читает `outputs/graph.json`, если его нет — `shared/sample_graph.json`.
2. `app/static/index.html + app.js + style.css` (без сборки, Cytoscape.js лежит в `app/static/vendor/`):
   - слева — топ-лист приоритетов (rank, gid, роль-бейдж, score), клик → фокус на узле;
   - центр — граф: цвет = роль, размер = priority, стрелки = направление, толщина = сумма; переключатель «весь граф / топ-100 + соседи / эго-сеть узла»; подсветка кластера;

   - сверху — поиск по gid (Enter → зум на узел + подсветка связей), легенда ролей;

### Даниал — AI-ассистент (`assistant/`)
1. **[14:40–15:20]** `assistant/llm.py`: клиент с выбором провайдера по `.env` (основной — NVIDIA; запасные OpenAI / Anthropic / none), таймаут 20 с, try/except, кэш ответов на диск.
2. `assistant/core.py::node_card` — сначала шаблонная карточка из метрик (работает без LLM), потом LLM-версия: роль, потоки, связи, «на что обратить внимание», осторожные формулировки.

4. `assistant/eval_questions.md` — 10 вопросов аналитика для проверки («кто собирает деньги с этих пятерых?», «покажи транзитные узлы кластера 3»…).
