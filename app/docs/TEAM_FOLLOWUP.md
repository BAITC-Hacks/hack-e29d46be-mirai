## Совместная приёмка

Полная сеть/поиск точного gid → выделение входящих/исходящих → карточка ребра → объяснение роли/приоритета → вопрос с контекстом → проверяемый путь → возврат к ответу. Обновление данных сохраняет корректный контекст либо явно сообщает о смене версии. Пересчитать outputs, чистый запуск, no-LLM и Windows. Временнóй фильтр требует дневных данных и отдельного согласованного этапа; основной интерактивный SVG-рендерер — только после сравнительных измерений, SVG-экспорт входит в работу Нурай.
