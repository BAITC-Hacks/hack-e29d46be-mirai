# Ассистент Даниала (#10–#12)

Публичный контракт: `assistant.node_card(gid, graph)` и `assistant.ask(question, graph)`.
Все gid в ответах и ссылках — строки. Изменения находятся только в `assistant/`.

## Запуск без ключа

Обычный запуск приложения: `python run.py`. При `LLM_PROVIDER=none`, пустом ключе,
ошибке API или превышении времени используются ответы из графа.

В `.env` можно оставить:

```dotenv
LLM_PROVIDER=none
LLM_MODEL=
```

Без LLM работают:

- три подсказки интерфейса: приоритеты, признаки консолидации, ограничения данных;
- карточка по точному gid, входящие и исходящие связи с суммами;
- роли, кластеры и их сочетание: «Консолидаторы кластера 3»;
- направленный путь между двумя gid;
- общие получатели от всех перечисленных gid (от 2 до 20 отправителей).

Примеры с настоящими gid нужно брать из открытого графа; список для проверки
генерирует `python -m assistant.evaluate --graph outputs/graph.json`.
Неизвестные gid не подменяются похожими. Отсутствующая сумма означает «не указано»,
нулевая сумма остаётся нулём. Показанный топ сопровождается общим числом совпадений.
Роль и приоритет — гипотезы, а не утверждения о личности или нарушениях.

Карточки используют подписи из `meta.flag_labels` и `meta.metric_labels`, если они
есть. `rapid_outflow` описывает близость дат исходящих и поступлений без
сопоставления сумм (`fast_forward_share`, доля исходящей суммы). `fast_transit`
опирается на FIFO-сопоставление входящих с исходящими через 1–2 дня
(`fast_transit_share`, доля входящей суммы). Эти значения показываются отдельно.
`terminal_unknown` сохраняет предупреждение, что конечный получатель не подтверждён.

## Необязательный LLM

Поддерживаются `nvidia`, `openai`, `anthropic`, `none`. Для выбранного провайдера
задайте соответственно `NVIDIA_API_KEY`, `OPENAI_API_KEY` или `ANTHROPIC_API_KEY`
в локальном `.env`. Ключи не коммитить. `LLM_MODEL` задаёт доступную вашему аккаунту
модель; пустое значение использует значение по умолчанию из `llm.py`.
Доступность конкретной модели и квоту проверяет провайдер; живые платные API
не входят в локальную проверку.

Дополнительные настройки: `LLM_TIMEOUT` (положительные секунды, максимум 20),
`LLM_MAX_TOKENS` (по умолчанию 700, максимум 2000), `NVIDIA_BASE_URL`, `OPENAI_BASE_URL`.
Некорректный таймаут заменяется значением по умолчанию. SDK не повторяет запросы.
Кэш ответов хранится локально в `.cache/assistant/`; ключ кэша учитывает провайдера,
модель, endpoint, лимит вывода, сообщения и инструменты, но не API-ключ.

**Как обеспечивается опора на данные.** LLM выбирает запросы к графу и затем номера
полученных результатов. На экран попадают тексты, построенные кодом из этих
результатов. Свободный текст модели не отображается. Для карточки модель выбирает
один следующий шаг из готового списка; факты и предупреждения карточки сохраняются.
`source=llm` означает успешный выбор моделью, а не свободное сочинение ответа.

Инструменты: `find_node`, `neighbors`, `top_by_role`, `cluster_summary`,
`path_between`, `common_recipients`, `data_limitations`. Параметры проверяются перед
выполнением. Нужен хотя бы один результат инструмента; неподтверждённый ответ сразу
откатывается к локальному запросу. До четырёх обращений к модели, до шести инструментов
в обращении; общий бюджет ожидания модели — 18 секунд, меньше серверных 25 секунд.
Одновременно допускается до четырёх фоновых запросов провайдеру; при занятых слотах
возвращается локальный ответ. Уже выполняющийся сетевой запрос нельзя принудительно
отменить этим кодом; он завершится по таймауту провайдера.

## Проверка

```powershell
python -m pip install pytest httpx
$env:LLM_PROVIDER = 'none'
python -m pytest assistant/tests -q
python -m assistant.evaluate --graph outputs/graph.json
```

Unit-тесты используют небольшие синтетические графы и заглушки API. Проверяются
пустая конфигурация, таймаут, кэш, исключения, потерянные поля, 18-значные gid,
четвёртое колено вместе с другими флагами, все подсказки интерфейса, совместные
фильтры, направления путей, общие получатели за пределами топ-20, вредоносный текст
модели, ошибки инструментов и проверяемые ссылки на узлы.

`assistant.evaluate` всегда отключает вызовы модели и строит 12 вопросов по файлу
графа, включая неизвестный gid. Скрипт проверяет ответы и ссылки; он не меняет граф.
Тесты сервера команды запускаются отдельно: `python -m pytest app/tests tests -q`.
